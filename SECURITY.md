# Reporting a security problem

DiscordMCP holds bot tokens for other people's Discord servers, so a report
about it is worth answering quickly and worth answering properly.

**Write to hello@discordmcp.com.** Please do not open a public issue for
anything that could be used before it is fixed.

Useful in a report: what you did, what happened, and what you expected. A
proof of concept is welcome and not required — a clear description of the
shape of the problem is usually enough.

You will get an answer from a person. If a report turns out to be right, you
will be told what was changed and when.

## What is in scope

Anything reachable at `discordmcp.com` or at an instance address
(`*.discordmcp.com`), and anything about how the service handles a customer's
bot token, their session or their data.

## What is not

Reports generated by a scanner with no analysis behind them, missing headers
that change nothing, and anything that needs a customer to hand over their own
credentials first.

Discord's own behaviour is Discord's — but if this service uses their API in a
way that surprises you, that is worth a message.
